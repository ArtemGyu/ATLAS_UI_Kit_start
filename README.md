# ATLAS UI Kit — Дизайн-система Help Desk

Учебный проект по созданию и масштабированию дизайн-системы с использованием CSS Custom Properties (дизайн-токенов) и Vanilla JS.

---

## 1. Схема цепочек токенов (`Primitive → Semantic → Component`)

В проекте реализована трёхуровневая архитектура токенов. Изменения на верхнем уровне автоматически каскадируются на компоненты:

1. **Цвет первичной кнопки:**
   `--color-blue-60` (Primitive) → `--color-primary` (Semantic) → `--button-bg-primary` (Component)

2. **Высота элементов управления в компактном режиме:**
   `--size-9` (36px, Primitive) → `--control-height-compact` (Semantic) → `--control-height` (Component)

3. **Внутренний отступ предупреждений:**
   `--space-2` (8px, Primitive) → `--space-alert-compact` (Semantic) → `--alert-padding` (Component)

## 2. Таблица проверок «Условие — Результат»

| Условие / Сценарий | Ожидаемый результат | Статус |
| :--- | :--- | :---: |
| **Переключение темы (Light / Dark)** | Тег `<html>` получает атрибут `data-theme="light"` или `dark`. Семантические цвета переопределяются, интерфейс мгновенно меняет палитру. |  |
| **Системная тема (`auto`)** | Атрибут `data-theme` удаляется с `<html>`. Включается CSS-медиазапрос `prefers-color-scheme`, тема подстраивается под ОС. |  |
| **Перезагрузка страницы (F5)** | Текущий выбор темы и плотности считывается из `localStorage` (`atlas-theme`, `atlas-density`) и применяются до рендера. |  |
| **Компактный режим (`compact`)** | Тег `<html>` получает `data-density="compact"`. Переопределяются компонентные токены высоты и отступов (`--button-height`, `--control-height`, `--component-gap`), сжимая весь UI. |  |
| **Состояние ошибки поля** | Поле с `aria-invalid="true"` получает красную границу, текстовая ошибка связывается через `aria-describedby`. |  |
| **Адаптивность (320px)** | Контент перестраивается в одну колонку, элементы не выходят за границы экрана, горизонтальный скролл отсутствует. |  |

## 3. Ответы на контрольные вопросы

### а) Почему плотность задаётся компонентными токенами?
Плотность изменяет размеры и отступы элементов интерфейса централизованно через переменные (`--button-height`, `--control-height`, `--component-gap`), что позволяет масштабировать весь UI целиком без дублирования стилей в классах компонентов. Это обеспечивает консистентность и гибкость дизайн-системы при переключении режимов отображения.

### б) Почему тёмная тема не должна хранить прямые цвета внутри `.button`?
Прямое указание цветов жестко привязывает компонент к конкретной палитре, нарушая изоляцию уровней абстракции. Использование семантических токенов позволяет кнопкам автоматически адаптироваться к любой теме через переопределение значений на уровне `:root`, сохраняя поддерживаемость и чистоту кода.
